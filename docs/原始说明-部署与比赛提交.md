## 路线 B：Qoder Sites 公网链接（比赛用，推荐）

`qoder-sites/dist-h5/` 是**自包含的静态演示站**：

- `demo-fixtures.js` 是从后台导出的清理后演示数据，不含真实个人信息；
- `demo-mock.js` 在浏览器里拦截 `/api/*`，让登录、列表、溯源、AI 规则问答、增删改都能操作；
- 所有操作只存在于当前页面内存，**刷新后恢复预置样例**，不会写入任何服务器。

### 1. 发布

在 Qoder 里选择发布目录：

```
田序/qoder-sites/dist-h5
```

公开访问权限选「任何人可访问」，确认状态到 `published: true`，拿到公开 URL。

**不需要再改 `window.__TX_API_BASE__`，也不需要另外部署后台。**  
只有想接真实后台时，才把这一行改成后台 HTTPS 地址。

### 2. 线上验收

用无痕窗口打开 Qoder Sites 链接：

1. 登录页能打开，验证码随便填 4 位，账号 `demo / demo123456`

### 3. 页面说明

- 桌面端左侧有工作台、生产、环境、溯源、产销、农技六个入口；
- 手机端是 5 个底部 tab，登录页、首页、生产、监测、溯源、产销、农技都已适配；
- 环境监测页顶部明确标注「演示数据 · 设备与环境记录来自预置样例」，设备状态显示「已接入」，避免把静态样例误认为实时在线设备；
- 农技问答默认走内置离线规则知识库，不联网、不产生费用；接入模型后自动切换，前端无需改动。

## 路线 A：完整后台（可选）

把 `deploy/` 整个目录上传到一台有公网 IP 的 Node 主机（阿里云 ECS、Railway、Render、宝塔、Cloud Studio 都行），然后：

```bash
cd deploy
npm ci --omit=dev
npm start
```

打开：

```
http://服务器IP:3000
```

- 同一个端口同时提供 `/api` 和 H5，不用再配前端地址
- **注意：`deploy/` 里的数据库是开发期副本，账号和问答不是比赛演示数据；比赛演示请走 B，不要在评委面前用 A**
- 首次启动会在 `deploy/server/data/jwt.secret` 自动生成独立密钥
- 想上 HTTPS：前面套 Nginx / Caddy，或者直接用同目录的 `Dockerfile` / `docker-compose.yml`

本机 Windows 想先试也可以：

```powershell
cd deploy
npm ci --omit=dev
npm start
```

## 常见问题

**Qoder Sites 打开是登录页，登录后没有数据？**  
确认发布目录是 `qoder-sites/dist-h5` 本身，不是上一层；确认 `demo-fixtures.js`、`demo-mock.js` 与 `index.html` 在同一目录。

**登录提示验证码错误？**  
演示层会校验验证码，按图片输入即可；如果看不清，点验证码图片换一张。

**页面空白 / 静态资源 404？**  
Qoder Sites 的发布目录必须是 `dist-h5` 本身，不能选成 `qoder-sites`。

**AI 问答能用吗？**  
默认走内置离线规则库，不联网、不产生费用。要接大模型，在 `deploy/.env` 里配置 `AI_PROVIDER` 和 `AI_API_KEY` 后重启。

**安全吗？**  
这是公开演示站，只有演示数据；不要往里填真实个人信息。`.env` 里没有 AI 密钥。正式长期运行建议改掉演示账号密码，并设置自己的 `JWT_SECRET`。
